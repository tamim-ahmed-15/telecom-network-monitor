# Telecom Network Monitoring & Anomaly Detection System

An end-to-end software project for telecom network KPI monitoring and anomaly detection.

The project combines telecommunications, data analysis, machine learning, backend development, databases, frontend development, and deployment.

## Current Status

🚧 Version 1 is under development.
